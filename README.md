# Window - Your Second Monitor (reImagined)

This is a very very simple web app that allows you to use your second monitor as window. It is simple and the picture will always be adjsuted to the size of your monitor. You can do a stare contest with the monitor.

# Why it took me so long to make this?

WINDOW took longer than expected because I experimented with different approaches to rendering realistic environments. I initially tried using static images but ran into resolution and quality issues, especially on larger displays. I then tested different rendering methods before switching to Three.js for a more immersive 3D experience. Along the way, I encountered bugs involving image loading, scene rendering, and frontend-backend communication. I spent time debugging these issues, testing different solutions, improving the visuals, and making sure everything worked properly before deploying the project.
